\section{Introduction}

In this project, we wanted to classify news articles from multiple sources using multiple datasets into one of five topics: Politics, Sports, Business, Technology, or Entertainment. We trained models using Data A and evaluated whether models trained on one news source could generalize to both unseen Data A articles and Data B articles. We also studied how regularization affected performance and later examined what happens when the classes change in Data C. 
Since machine-learning classifiers require numerical input rather than raw text, we represented each news article using term frequency inverse document frequency (TF-IDF) features. For each example we concatenated the article title and description the converted the text into a unigram TF-IDF vector. TF-IDF gives greater weight to words that are important in a specific article but less common across all articles. This allows the models to use words that are related to the article specifically while reducing the impact of common words across multiple articles. 
We compared two models which were logistic regression (LR) and multi-layer perceptron (MLP. LR provides a linear baseline that predicts a topic from a weighted combination of TF-IDF features. The MLP uses two hidden layers with ReLU activation functions which allow it to learn nonlinear relationships. We selected regularization settings using a validation split from Data A only then refit the selected models on all available Data A training data. Then Data A and B were used for model selection and training.

\section{Part 1: Exploratory Data Analysis}\label{section:eda}

For this part, we wanted to make sure to clean the data. Cleaning the data helps to make sure that the data is accurate for the model to learn and it keeps the model from encountering any errors that may prevent it from correctly learning the model. For this part we only cleaned dataset\_a\_train. 
The total number of examples before data cleaning was about 7500. After dropping duplicate examples and examples with null values, the data decreased to about 7,453 examples. The 47 examples that were removed all belonged to the class "Technology." Therefore, there were 1500 examples for each class and Technology had about 1,453. 
Duplicate examples could give more weight to certain examples on accident while null examples can confuse the model by taking in a Title or Description instead of both. 
For this project, each token consists of exactly one word. The description and title are split according to spaces to account for this. We calculated the distributions of both the Title and Description using Matplotlib's boxplot functions.

\section{Part 2: In-Domain Performance on Dataset A}

We start by comparing the performance of the multilayer perceptron (MLP) with logistic regression (LR) on Dataset A.
The training dataset was partition using stratified sampling into $6,000$ training and $1,500$ validation examples, preserving the class distribution in both sets.
A raw unigram TF-IDF vectorizer was fit exclusively on the training partition.
The Title and Description fields were concatenated for each article so that both headline and contextual information were available for the models. Since LR serves as a linear baseline, whereas the MLP introduces nonlinear transformations to the TF-IDF representation, comparing the two models therefore allows us to examine whether the extra nonlinear capacity of the MLP improves in-domain classification.

For the MLP, we focus on designing a stable model with sufficient capacity to capture nonlinear feature while controlling overfitting. As shown in Table \ref{table:lr_mlp_architectures}, the MLP uses two hidden layers with 128 and 64 units, respectively.
The first hidden layer transforms the high-dimensional TF-IDF input into 128 latent features, which are further reduced to 64 featues before the final output layer.
ReLU activations introduce nonlinearity, while dropout and L2 regularization are used to reduce overfitting.
Both models were trained using SGD with a batch size of 32 and cross-entropy loss as an optimizing. LR used a learning rate of $0.01$ while the MLP used a learning rate of $0.024$, momentum of $0.9$, dropout rates of $0.2 \to 0.3$, and $\mathcal{L}2$ regularization (weight decay) of $10^{-3}$. Training duration was determined based on the model's validation behavior with an early-stopping patience of five epochs.
%LR continued improving through its maximum of $50$ epochs, whereas the MLP achieved its best validation loss at epoch $11$.
After these decisions were fixed, the vectorizer was refit on all $7,500$ examples in the Dataset A training set, and both models were re-trained using their selected training durations before a single evaluation on the 2,500-example Dataset A test set.

From the error analysis, we observe that LR misclassified $1,211$ of $2,500$ test articles, whereas the MLP misclassified $1,134$. A follow-up qualitative inspection of ten representative errors reveals four distinct patterns: Politics--Entertainment overlap, Business--Technology overlap, Sports--Entertainment overlap, and cases in which the description is usually short or poorly correlated to its corresponding category.

%TABULAR: error examples%

The class-wise results further show that the MLP performs most effectively on Sports and Technology, with F1 scores of $0.6678$ and $0.6777$, respectively, whereas Politics and Entertainment remain the most difficult categories.
This pattern may be explained by overlapping vocabulary among different classes and by articles whose descriptions provide limited additional information about the article's topic.
For example, company-related articles can contain vocabulary associated with both Business and Technology, while stories involving public figures may contain cues associated with both Politics and Entertainment. These overlaps make the class boundaries difficult to determine using lexical TF-IDF features alone.

\textbf{Summary.} The MLP provides an improvement in in-domain performance over the linear baseline, with higher overall accuracy and macro-F1. However, the relatively modest increase in macro-F1 indicates that nonlinear modelling does not necessarily eliminate ambiguity between semantically overlapping classes. The class-wise and error-analysis results suggest that the remaining errors are associated with lexical overlap, weakly informative descriptions, and source-specific patterns identified during EDA.

\section{Part 4: Cross-Dataset Transfer to Dataset C}

We applied two frozen Part 3 models directly to Data C testing set, which has 2,000 articles of which 500 are in each of labels 1 through 4 evenly. The Part 3 TF-IDF vectorizer was only used with transform, so Data C articles are being represented using the Data A vocabulary that has 19,834 terms and neither model was retrained. As an in-domain reference, we trained separate models on the Data C training set but they were never combined with the transferred models. We also checked to ensure no Data C test set articles were identical to any of the Data A train set articles nor Data C train set articles and the check showed that there were indeed no overlapping articles. The first model we used is the logistic regression model with a single linear layer with 5 outputs trained at learning rate 0.01, weight decay 1e-5 and batch size 64 for 6 epochs. The second is the MLP with two hidden layers of 128 and 64 units with ReLU activations and dropout of 0.2 and 0.3 and trained with a learning rate 0.001 with no weight decay and batch size 64 for 2 epochs. Both of these models were trained on all 7,500 articles in Data A training set with seed 0.

For the labels, sports, business, and technology mean the same thing in Data A and Data C so we analyzed the 1,500 test articles with true labels of 2, 3, and 4. We computed macro-F1 for those three labels where a prediction of 1 or 5 counted as an error. LR reached 0.587 accuracy and 0.629 macro-F1. The MLP reached 0.599 accuracy and 0.638 macro-F1. By analyzing the results, sports transferred well with an F1 of 0.812 on LR and 0.819 on MLP. This is likely because the vocabulary of team names and scores are distinct compared to the other categories. Business and Technology on the other hand were much weaker with F1 between 0.46 and 0.48. This first figure shows that they are confused with each other far more than with any other class. LR labelled 138 Business articles as Technology and 165 Technology articles as Business. The MLP did the same with 156 and 171. Data C business and technology new share a lot of company and market vocabulary that Data A didn't separate well.

If we compare this to Data B, the shared label transfer to Data C is weaker than Data B in part 3 which had a macro-F1 of 0.79. It was also interesting to see that categories with the same meaning still lost accuracy as the source and writing style changed.

Comparing Data A and Data C, the semantic transfer of label 1 changed from Politics in Data A to the broader category World. LR precision became 0.592, recall became 0.430, and F1 became 0.498. Similarly, MLP precision became 0.607, recall became 0.392, and F1 became 0.476. From the 500 true World articles, LR predicted 215 as label 1 and MLP predicted 196. The most common words absent from Data A that led to missed classifications primarily came from terminology about countries like EU, India, and Nigeria or economic terms like prices and crude oil, as well as some international sports terminologies like Olympics and games. We also noticed that terms like "afp" and "quot" showed formatting differences between the datasets.
As an in-domain reference, our models were trained on Data C with the same Part 3 settings of an 80/20 split of the data, TF-IDF vectorizer on 17303 terms rather than the original 19834 terms, and early epoch stopping on the macro-F1 validations. These models were trained on Data C testing set and as a result never predicted label 5 as they were never exposed to that label in training. This change allowed us to see the true impact of changing label 1 from Politics to World resulting in a F1 of 0.379 for LR and 0.388 for MLP.

\section{Part 5: Limited-Data Adaptation to Dataset C}

In this part, we started from the final Part $3$ models and added a limited number of Data C training articles to see how much a small amount of target-domain data helps. Both models kept the settings selected in Part $3$, which were chosen without any Data C test results. Logistic regression used a learning rate of $0.01$ and weight decay of $1e-5$ for $6$ epochs. The MLP used a learning rate of $0.001$, no weight decay, and dropout of $0.2$ and $0.3$ for $2$ epochs. Both models used Adam with a batch size of $64$, unigram TF-IDF features on the title and description, and random seed $0$. Every added article came from the Dataset C train set. The Data C test set was only used for evaluation.
We tested budgets of $50$, $150$, $600$, and $1,500$ added articles with three sampling strategies. The label $1$ only strategy adds Data C World articles. The shared labels only strategy adds Sports, Business, and Technology articles, split as evenly as possible, so a budget of $1,500$ adds $500$ from each class. The balanced strategy adds about the same number from all four classes, which gives $375$ per class at $1,500$. To make the sampling reproducible, each Data C class was shuffled once with seed $0$, and every sample takes the first $n$ articles from each shuffled class. Because of this, a smaller sample is always contained in a larger one. For every condition, we refit the TF-IDF vectorizer and the classifier on Data A train plus the sampled Data C articles, so the training set grew from $7,500$ articles to as many as $9,000$. The zero-example baseline is the frozen Part $3$ model, and it was run once per model.

\section{Part 6: Text-Representation Extension}

In the previous sections, we analyzed the performance of different models using datasets represented with unigram TF-IDF features. In this section, we extend the text representation by using bigrams in addition to unigrams and examine how the resulting increase in feature dimensionality affects model performance. The experiments are designed to answer the following questions: (a) How do the models respond to the increased feature dimensionality introduced by bigram features? (b) Does the unigram--bigram representation improve both in-domain performance and cross-dataset transfer compared with the unigram baseline? and (c) Does the extended representation improve model adaptation to Dataset C when limited target-domain training examples are added?

As shown in Table \ref{table:feature_sizes_uni_bigrams}, the unigram produces a vocabulary of $19,834$ features when fitted on the full Dataset A training set. By using both unigrams and bigrams with \texttt{min\_df=2}, the vocabulary increases to $31,068$ features, corresponding to an increase of approximately $56.64\%$.
Bigrams allow the representation to preserve short two-word pairs that may carry more specific semantic information than individual words. For example, phrases such as "prime minister" or "stock market" may provide stronger class-related information than the individual terms considered separately.
Note that the extension changes only the text representation; the data splits, random seed, model hyperparameters, and evaluation metrics remain unchanged. This controlled comparison isolates the effect of feature representation as far as possible. The final LR configuration uses unigram--bigram TF-IDF with \texttt{min\_df=2}, Adam, learning rate of $0.01$, $\mathcal{L}2$ regularization of $10^{-5}$, epochs of $11$, and batch size of $64$. The final MLP uses $128 \to 64$ ReLU hidden units and dropout layers with the rates of $0.2 \to 0.3$, Adam with learning rate of $0.001$, epochs of $8$, and batch size of $64$. After refitting on all $7,500$ Dataset A training set, both models run on a $31,068$ vocabularies.

\section{Conclusion}

In this work, we systematically analyzed the generalization and adaptation performance of custom MLP models under different settings and hyperparameters. Our experiments demonstrated the MLP's generalization ability in three different settings: in-domain performance on Dataset A was limited by topical overlap and source-specific patterns; cross-source transfer to Dataset B achieved strong overall performance while exhibiting noticeable changes in class-wise precision and recall; and the semantic category shift in Dataset C revealed limitations in transferring a decision boundary to a dataset with a different class composition.
The adaptation experiments provided the clearest evidence of the effects of category mismatch. World-only sampling increases World recall but reduces performance on the remaining classes, whereas shared-label-only sampling improves performance on non-World classes at the expense of World recall. Balanced sampling mitigates both effects by adding World examples along with examples from the other classes, helping the model classify World while preserving its ability to distinguish among the remaining categories.
In a further analysis, we showed that increasing feature dimensionality does not necessarily improve transfer performance. Using bigrams increases the full-training vocabulary size by 56.64\% but generates inconsistency in performance improvements before adaptation to Dataset C and, overall, underperform the corresponding unigram models. Based on these results, we conclude that unigram TF-IDF provides the more effective and consistent text representation for the final models.
